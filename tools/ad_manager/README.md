# ad_manager

Reservado para a ferramenta Python que cria os acessos dos alunos no Active Directory.

Para preencher quando a integração começar:
- Quais colunas da planilha do Sponte a ferramenta lê hoje (nome, e-mail, CPF, turma, curso...).
- Quais delas já existem no DW (`dw.dim_aluno`, `dw.dim_turma`, `dw.fato_matricula`).
- Onde registrar o resultado da criação de cada conta.
